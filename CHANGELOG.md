# Changelog

## 1.0.0

- Manifest-based installer with guided setup and explicit configure, build, flash, device detection and Wi-Fi setup commands.
- Pip TFT, Pip OLED and Codey TFT firmware profiles with pinned build dependencies.
- Local browser companion, token pairing, bounded device protocol and optional server-side AI replies.
- Optional macOS Codex metadata integration, lifecycle observers, and BOOT task navigation.
- Automated installer, protocol and firmware checks; source release packaging with checksums.
